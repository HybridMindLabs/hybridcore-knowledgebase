# Changelog

All notable changes to the `hybridcore/knowledgebase` extension will be documented in this file.

## [1.0.0] - 2026-10-18
### Added
- Initial release of Knowledgebase extension.
- Categories management with custom icons, colors, and order.
- Article management with rich content, slugs, SEO meta, pinned & featured flags.
- Public portal with category cards, featured articles, search, and reading view.
- Live search and global Ctrl+K search provider.
- Helpfulness feedback (useful/not useful) with comment reporting.
- Search misses tracking in Admin panel.
- Dark & Light mode theme support.
- Bulgarian and English translations.
